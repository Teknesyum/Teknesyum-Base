Commit git kimliği yüzünden başarısız olur ve push "Everything up-to-date" dönerse komut
**"Push tamam."** yazar — dosya depoya gitmemiştir. İlk push'ta upstream kurulmuyor.
`pull --ff-only` sonucu da yok sayılıyor, ardından eski cache açılabilir.

Ayrıca proje adı `path.join(klon, ad, ...)` biçiminde kullanılıyor (`:169`, `:205`,

`coz()` tarafından `path.resolve` ediliyor; bozuk manifest + `--zorla` proje dışına
yazma sınıfı üretir.

## Kabul kriterleri

1. Proje adı `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` politikasından geçer; `.`, `..`, sürücü
   harfi, UNC ve ayraç reddedilir.
2. Her kaynak/hedef için `path.resolve` sonrası `path.relative(izinliKok, hedef)`
   containment kontrolü; symlink/junction için `realpath`.
3. Git yardımcısı `{ok, status, stdout, stderr}` döndürür; add, commit, pull, push
   aşamalarının her biri ayrı kontrol edilir.
4. "nothing to commit" ile gerçek commit hatası ayrılır; commit SHA gösterilir; ilk
   push'ta `--set-upstream origin <dal>` kullanılır.
5. Başarı mesajı yalnız uzak dalın beklenen commit'i taşıdığı doğrulandıktan sonra yazılır.
6. Test: `../x`, mutlak/UNC yol, symlink kaçışı, bozuk manifest, eksik git kimliği,
   detached HEAD, upstream yok, auth hatası, merge gerekli, boş commit.
