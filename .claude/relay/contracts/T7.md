## Amaç
Teknesyum mesajlarını Claude Code arayüzünün desteklediği en görünür ve taşınabilir biçime getir; kullanıcıdan aksiyon gerektiğinde zorunlu `Senden istediklerim` bloğunu relay kuralına ekle; ajan ölüm nedenini raporlama belirsizliğini azalt.

## Kabul kriteri
- Hook çıktısı `systemMessage` üzerinden renk/ANSI dayatmaz; Claude Code'un renk API'si yoksa ANSI kodları metne sızmaz. Mevcut düz metin mesajlar belirgin başlık/etiket biçimiyle okunabilir kalır.
- Başarı/etki bildirimleri mevcut teknesyum-ui success tokenı (#34d399) ile metinsel olarak tutarlı isimlendirilir veya platform desteklemiyorsa renk iddiası yapılmadan raporlanır; yeni renk uydurulmaz.
- Relay SKILL.md içinde kullanıcıdan aksiyon/karar beklendiğinde cevabın sonunda `Senden istediklerim` başlığı ve numaralı, exact copy text içeren maddeler zorunlu olur. Aksiyon yoksa başlık yazılmaz.
- `report.md` ölü/kayıp ajanlarda `stop_reason: other` veya eksik nedenin kesin kök neden olmadığını açıkça belirtir; dosya çakışması kanıtlanmadıkça çakışma iddia etmez.
- `relay-watch.js` mevcut JSON sözleşmesini bozmaz; node --check ve mevcut npm test geçer.
- Kod yorumu yazılmaz.

## Bağlam
Hook `systemMessage` alanında düz string üretir. Agent renk metadata'sı ajan tanımlarında vardır ama kullanıcıya dönen systemMessage için renk taşımaz. Mevcut `report.md` stop_reason değerlerini sınıflandırır. `RULES.md` kullanıcı aksiyonu varsa `Senden istediklerim` bloğunu ister; bu proje skill'inde kalıcı kural olarak görünür olmalıdır.
