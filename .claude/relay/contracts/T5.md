## Amaç
Mevcut banner, akış görseli ve Support bölümünü teknesyum-ui kurallarına göre düzelt; görsel taşmasını gider, metinlerde Title Case/ilk harf büyük kuralını uygula ve proje yapısını neon mimari görünümle daha anlaşılır sun.

## Kabul kriteri
- `assets/banner.svg` içindeki alt vurgu/çizgi kendi viewBox ve çerçeve sınırları içinde kalır; görüntü veya CSS dışına taşmaz.
- Banner alt etiketleri `Relay`, `Contracts`, `Hooks`, `Audit`, `Prior Art` olarak Title Case görünür.
- `assets/flow.svg` içindeki kullanıcıya görünen doğal dil etiketleri ilk harfi büyük olur: `Request`, `Measure`, `Prior Art`, `Builder · Scribe · UI-Builder`, `Auditor`, `Return Block`, `Contracts/Done`, `Hooks · 11 Events`, `Syntax Check`, `Status Ladder`, `Prior-Art Gate`, `Return-Block Floor`, `Teknesyum ▸ Steering`.
- Teknik dosya/yol adları ve marka/kısaltmalar (`PLAN.md`, `UI-Builder`, `Contracts/Done`) okunabilirliği bozacak şekilde değiştirilmez.
- README'deki başlıklar ve kullanıcıya görünen akış/sponsor metinleri ilk harf büyük kuralına uyarlanır; İngilizce dış doküman kuralı korunur.
- README'nin `How It Works` bölümünü destekleyen mevcut `flow.svg` görseli daha görünür ve kapsamlı bir neon mimari/akış görseli olarak korunur veya iyileştirilir; yeni renk/ölçü uydurulmaz, mevcut SVG tokenları kullanılır.
- README `Support` bölümü mevcut ücretsiz destek, sponsor bağlantısı, GitHub bağlantısı ve MIT bilgisini koruyan neon bir panel görünümü kazanır. GitHub README Markdown/HTML uyumluluğu korunur; harici asset veya yeni bağlantı uydurulmaz.
- SVG'ler geçerli XML olarak kalır, viewBox dışı çizim içermez; README görsellerinin alt metinleri güncellenmiş görünümü açıklar.
- Hiçbir komut veya uicheckup onay akışı bu sözleşmede değiştirilmez.

## Bağlam
`assets/banner.svg` ve `assets/flow.svg` mevcut neon renkleri doğrudan kullanır. Banner'ın alt çizgisi `y=296..300` ile viewBox alt sınırına dayanıyor ve kullanıcı görselinde taşma gözleniyor. README Support bölümü 558. satır civarında düz Markdown/HTML içeriktir. `teknesyum-ui` kontrast, neon triad, metin hiyerarşisi, başlıkların ilk harfi ve çizimlerin komşu sınırları kapatmaması kurallarını uygula. Yeni tasarım dili icat etme.
