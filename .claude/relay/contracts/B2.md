# B2 · Toplayıcı, pano, rapor

Kaynak: başkanlık konseyi bench planı + kullanıcı isteği: "token tüketimi, süre, yapılan
iş, bug oranı vb detaylı; kripto madenci panosu gibi". B1 bitmeden başlamaz.

## Toplayıcı — scripts/bench/topla.js

- `scripts/olcum/taban.js`'in `ozetle()`'si modül olarak çağrılır, yeniden yazılmaz.
- Alt ajan transkriptleri de gezilir (`relay-defter.js` kalıbı) — alt ajan tokenları
  sayılmazsa premium sistematik ucuz görünür.
- Koşu başına: dört token kalemi ayrı (input / cache-create / cache-read / output),
  duvar saati, tur sayısı, ajan sayısı, model id.

## Madenci panosu — scripts/bench/pano.js

- `kos.js` koşarken terminale canlı tablo: hücre = koşul × görev, içinde durum
  (bekliyor/koşuyor/bitti/tavan), geçen süre, büyüyen token sayacı (transkript dosya
  boyutundan yaklaşık, bitince kesin).
- Bitişte verim satırı: koşul başına iş/dakika, token/görev, başarı yüzdesi.

## Rapor — docs/BENCH-SONUC.md (+ ham bench/sonuc/*.json kalıcı)

- Tablo: satır görev, sütun koşul; hücre = başarı(0/1) · 4 token kalemi · süre · tur ·
  ajan. Tek toplam token yazılmaz (BENCH-YONTEM.md §5).
- Bug oranı: `dogrula.js`'in bulduğu kusur sayısı / görev, koşul başına toplanır.
- n=1 şerhi: fark ancak büyükse "fark" diye yazılır, yoksa "ayırt edilemedi".

## Kabul

- Toplanan token kalemleri, bir koşunun harness sayacıyla ±%5 içinde (B0 verisiyle sağlanır).
- Pano 16 koşuluk gerçek koşuda okunur ve donmaz.
- Rapor tek komutla üretilir: `node scripts/bench/topla.js && node scripts/bench/rapor` ya
  da topla.js'in kendisi raporu da yazar (uygulayıcı seçer, belgeler).

Kanıt: gerçek koşudan BENCH-SONUC.md + pano ekran çıktısı.
